# LabReserve
REST API for managing laboratory room and equipment reservations.

## Status
Planning stage. No application code has been implemented yet.

## Goal
Build a backend application focused on business rules, relational
databases, automated testing and reliable reservation management.

## Planned features
- User authentication and role-based access.
- Room and equipment registration.
- Reservation creation and cancellation.
- Prevention of overlapping reservations.
- Reservation history.

## Planned stack
- Java and Spring Boot
- PostgreSQL
- Maven
- JUnit
- Docker
- GitHub Actions
